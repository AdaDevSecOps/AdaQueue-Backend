Staff Console APIs

POST /api/staff/console/call-next

Call Next Queue - เรียกคิวถัดไปที่รออยู่

📥 Request Body

{
  "profileId": "TEST-PROFILE-001",      // Optional
  "serviceGroup": "Q-TEST-001"          // Optional
}

📤 Response (Success - Queue Found)

{
  "success": true,
  "message": "เรียกคิวสำเร็จ",
  "queue": {
    "docNo": "Q1739702400000",
    "queueNo": 1,
    "customerName": "คุณสมชาย ใจดี",
    "tel": "081-111-1111",
    "status": "CALLING",
    "queueType": "Q-TEST-001",
    "data": {
      "serviceGroup": "Q-TEST-001",
      "profileId": "TEST-PROFILE-001",
      "category": "GENERAL"
    }
  }
}

📤 Response (No Queue Available)

{
  "success": false,
  "message": "ไม่มีคิวที่รออยู่",
  "queue": null
}
GET /api/staff/console/actions

Get Allowed Actions for a Queue

🔍 Query Parameters

docNo - Document number (e.g., Q1739702400000)
industry - Industry type (e.g., BANK)

📤 Response

{
  "docNo": "Q1739702400000",
  "currentState": "WAITING",
  "actions": [
    {
      "label": "เรียกคิว",
      "targetState": "CALLING",
      "actionType": "TRANSITION",
      "color": "primary"
    }
  ]
}
POST /api/staff/console/execute

Execute Action to Change Queue State

📥 Request Body

{
  "docNo": "Q1739702400000",
  "action": "CALLING",
  "industry": "BANK"
}

📤 Response

{
  "docNo": "Q1739702400000",
  "oldState": "WAITING",
  "newState": "CALLING",
  "message": "State updated successfully"
}
